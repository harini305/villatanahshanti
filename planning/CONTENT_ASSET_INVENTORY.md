## 9. Asset download plan (Phase 2)

1. A script downloads the 64 originals plus the poster and favicon to a gitignored `assets-src/` folder (≈260 MB).
2. It pre-optimises with `sharp` (bundled with Next.js): long edge 2560 px, mozjpeg quality ~80, metadata stripped. Output goes to `public/images/<section>/<descriptive-name>.jpg` (e.g. `rooms/agung-hero.jpg`). The logo stays a PNG and is also exported as a 512 px PNG for icons.
3. `next/image` then serves responsive AVIF/WebP sizes.
4. Video: transcode with ffmpeg (D8).
5. A mapping file `src/data/images.js` records the original Wix ID, new path, width, height and alt text for traceability.
